# Temporal model

Metroplist distinguishes four clocks:

1. Reference time — when the observation describes.
2. Boundary time — which geography and boundary version applies.
3. Publication time — when the source released it.
4. Knowledge time — when Metroplist ingested and verified it.

Timeline comparison modes:

- As originally reported
- Consistent fixed boundary
- Latest revised or rebased series

The interface must explain when a change may arise from boundary or methodology changes rather than the underlying population or environment.
