# Comparison rules

Comparisons operate on canonical observations rather than stored directional sentences.

`/compare/greenwich/bromley` and `/compare/bromley/greenwich` may use the same neutral pair and observation records. The route changes the narrative perspective.

Comparison modes:

- like for like;
- approximate equivalent;
- nested scale;
- urban-form contrast;
- historical contrast;
- country comparison;
- illustrative only;
- not comparable.

Units, indicator definitions, reference periods, boundaries and geographic scales must be checked before calculation. A mathematically possible ratio may still require an incompatibility warning.
