# Metroplist Data Foundation v0.1

## Purpose

Metroplist records places as measurable environments and reveals relationships between them.

The first public relationship query is:

> How does living here differ from living there?

Density is the first expression, not the limit of the system.

## Permanent logical objects

1. Place identity
2. Place names and external identifiers
3. Geographic definitions
4. Boundary versions
5. Indicators and units
6. Time-specific observations
7. Publishers, datasets and releases
8. Calculations and input lineage
9. Comparison frames and requests
10. Versioned knowledge claims and evidence
11. Ingestion and validation events
12. Demand-led data requests
13. Research sources and concept lineage
14. Historical and user-defined scenarios
15. Explicit composite geographies

## Data layers

External evidence passes through:

raw → staging → canonical → derived → presentation

Public requests should normally read canonical or derived Metroplist records. Unknown evidence must be acquired, quarantined, validated, resolved and approved before publication.

## Release 0.1 boundary

Release 0.1 establishes the complete path through the architecture while activating only population, land area and population density definitions. It seeds no observed place values.
